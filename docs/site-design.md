# SIAN会社サイト 設計メモ（2026-09-11 承認済み）

## 目的・スコープ

- **目的**: 信頼獲得の名刺代わり。工務店・住宅会社や取引先が社名検索したときに、
  事業内容と会社情報がきちんと伝わる公式サイト
- **スコープ**: 1ページ完結。まずはローカル表示のみ（公開・ドメイン設定は将来対応）
- 会社概要の実データ（代表者名・所在地・設立年月日）は【要記入】プレースホルダで作り、
  公開前に実データへ差し替える

## ページ構成（上から順）

1. **ヒーロー** — 深い青のグラデーション（思案＝深く水中に潜るモチーフ）。
   社名＋タグライン「建物のあらゆる情報をデザインする」
2. **社名の由来** — S・I・A・N（Spatial Information of Architecture and Nature）の展開
   ＋「思案」とのダブルミーニング
3. **行動指針** — 思案の3要素（知的忍耐力・知的好奇心・観察眼/洞察力）をカード3枚
4. **事業内容** — 建築情報設計を主役に、木造構造設計・PonkozAIを事業の柱として紹介
5. **会社概要** — 表形式（社名・代表・所在地・設立・事業内容・連絡先）
6. **お問い合わせ＋フッター** — メールリンク（y@sian.bz）

## デザイン（2026-09-16 全面改訂: 深海イマーシブ）

- **DADSは不採用**（ユーザー指示: 「DADSは一切無視でいいので、めっちゃおしゃれに」）。
  資料テンプレの視覚DNAとは切り離し、サイト独自の世界観で作る
- **深海イマーシブ**: 漆黒〜深紺（`#030612`〜`#0a1440`）の背景。下へスクロールするほど
  暗くなるグラデーション＝「深く潜る」体験。漂う光のオーブ・差し込む光の筋・
  立ちのぼる泡・粒状ノイズで水中の空気感を出す
- **タイポグラフィ**: 見出しはしっぽり明朝（Shippori Mincho）×Cormorant Garamond の
  明朝・セリフ高級路線。本文は Noto Sans JP Light。アクセントは生物発光シアン `#7fd8e8`
- **演出**: ヒーローのSIAN一文字ずつ浮上、ガラス質感カード（hover発光）、
  スクロール連動フェードイン、左下に「現在深度メーター」（スクロール量→最深40m表示）
- プレースホルダは琥珀色＋破線枠で見落とし防止
- レスポンシブ（スマホ対応）

## 検証時の注意（headless Edge）

- アンカー付きURL撮影は仮想時間下でIntersectionObserverが発火せず真っ白になる
- 全ページ確認は `_snap.html`（scroll-behavior無効＋reveal常時表示＋hero高さ固定の
  一時コピー）を作り、縦長window一括撮影→クロップで行う。撮影後に削除
- window幅の最小は約500px。スマホ最小幅（390px等）は500px撮影＋計算で担保する

## 技術構成

- `index.html` ＋ `css/style.css` の2ファイル。ビルド不要、file:// でそのまま表示可能
- JSはスクロール時のフェードインのみ（IntersectionObserver）。JS無効でも全文閲覧できる
- フォントは Google Fonts（Noto Sans JP）＋オフライン時 Yu Gothic フォールバック
